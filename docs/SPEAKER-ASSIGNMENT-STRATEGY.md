# 미배정 감소 전략

상태: 2026-09-25 코드·저장 결과 조사에 근거한 제안. 아래 개선은 아직 화자 배정 알고리즘에 적용하지 않았다. 기존 결과와 실행 중인 분석을 변경하지 않는다.

## 실제 결과에서 확인한 문제

사용자가 보여 준 1시간 50분 28.9초 분석 결과의 저장본을 읽기 전용으로 집계했다. 음성·자막 본문·개인별 이름은 이 문서에 포함하지 않는다.

| 항목 | 자막 수 |
| --- | ---: |
| 전체 | 3,323 |
| 미배정 | 985 (29.6%) |
| 미배정 중 겹침 표시 | 493 |
| 미배정 중 시간 모호성 표시, 겹침 없음 | 5 |
| 미배정 중 위 두 표시 없음 | 487 |

487개 중 147개는 0.8초 이하, 421개는 1.5초 이하이다. 이 가운데 앞뒤 바로 인접한 두 자막이 같은 인물이고 양쪽 간격이 각각 200ms 이하인 사례는 201개였다. 시간 모호성·경계 보정이 붙은 인접 자막은 이 집계의 근거에서 제외했다. 이것은 검토 후보 수이며, 201개를 올바르게 자동 배정할 수 있다는 증거가 아니다. 짧은 추임새를 다른 인물이 끼워 말할 수 있다.

저장 결과에는 원본 화자 활동 구간과 점수가 없다. 따라서 487개를 '활동 검출 누락'과 '활동은 있지만 시간 중첩 비율 부족'으로 정확히 나누거나, 겹침 493개가 모두 실제 동시 발화인지 확인할 수 없다. 원음 청취 없이 현재 집계만으로 배정 정확도를 주장하지 않는다.

## 현행 코드의 한계

`backend/voicesubsep/inference.py`의 `_attribute`는 단어 시간의 60% 이상을 한 화자가 차지하고 다음 화자가 20% 미만일 때 배정한다. 서로 다른 화자의 활동이 아주 조금이라도 실제 시간상 겹치면 단어 전체를 미배정 처리한다. 작은 경계 오차도 겹침으로 번질 수 있는 구조다.

`_compensate_speaker_boundaries`는 최대 0.8초 단어에 실제 활동 중첩과 200ms 이내의 확실한 이웃 단어가 있을 때만 보정한다. 보정값은 기본 500ms이며, 활동 중첩이 전혀 없거나 ASR 레코드가 다르면 보정하지 않는다. 이 보호 조건을 일괄 해제하면 다른 인물의 짧은 대사와 무음 오인식까지 잘못 배정할 위험이 있다.

## 권장 순서

1. **미배정 원인과 근거를 보존한다.** 화자 활동 없음, 시간 경계 불일치, 화자 전환, 동시 발화, 비음성 의심을 분리한다. 자막별 활동 중첩량·후보 인물·판정 방식을 저장하고, UI에서는 짧은 이유와 후보만 표시한다. 기존 결과는 근거가 없는 항목을 '원인 상세 없음'으로 유지한다.
2. **비겹침 경계부터 개선한다.** 같은 연속 발화 안에서 ASR 레코드 경계를 넘는 확실한 단어 근거를 활용한다. 실제 화자 활동과 비음성 검사를 유지하며, 시간만 가까운 대사를 자동 연결하지 않는다. 단어 시간이 맞지 않는 구간은 해당 구간만 정렬을 다시 검토한다.
3. **인물별 확인 음성을 등록하고 후보를 추천한다.** 사용자가 확인한 깨끗한 단독 발화 여러 구간으로 음성 특성 기준을 만들고 미배정 구간을 비교한다. 충분한 음성이 없는 짧은 추임새는 앞뒤 맥락과 함께 검토한다. 점수 차가 작은 후보는 자동 확정하지 않고 '추천 인물 · 근거 듣기 · 적용'으로 제공한다. 새 모델 선택·성능·라이선스·배포 크기 검증이 필요한 별도 단계다.
4. **겹침은 따로 다룬다.** 미세한 경계 겹침과 지속적인 동시 발화를 원음 표본으로 구분한다. 한 사람이 우세하다는 이유만으로 두 사람의 대사를 한 사람에게 붙이지 않는다. 인물별로 분리된 원본 트랙이 있으면 트랙 매핑을 우선 활용한다. 음성 분리·다중 대사 복원은 별도 평가 대상으로 둔다.
5. **검수 비용을 낮춘다.** '추천 있음 / 겹침 / 활동 없음'으로 필터링하고 앞뒤 1~2초 듣기, 후보 비교, 선택 항목 적용, 실행 취소를 제공한다. 확정한 인물·검수 완료·수동 수정은 재분석으로 덮어쓰지 않는다. 반복 확인한 음성만 추천 기준에 반영한다.

## 검증 기준

- 위 분류마다 실제 음성 표본을 먼저 확인한다. 같은 인물 사이에 다른 인물의 추임새, 긴 침묵, 무음 환각, 2명 동시 발화, 배경음, ASR 레코드 경계를 포함한다.
- 단순 미배정 비율과 함께 새로 배정한 자막의 오배정률, 시간 가중 비율, 후보 수락률, 수동 검수 시간을 측정한다. 문장을 잘게 나누어 미배정 비율만 좋아 보이는 것을 방지한다.
- 음성 기준을 만든 구간과 평가 구간을 분리한다. 정답을 확인하지 않은 사용자 결과로 정확도 목표를 달성했다고 판단하지 않는다.
- 전후 결과를 비교하고 변경된 자막만 검토할 수 있게 한다. 기준 모델·설정·원인·변경 내역을 보존한다.

첫 개발 범위는 **원인 집계 + 비겹침 경계 보완 + 검토 후보 표시**를 권장한다. 인물별 음성 비교와 겹침 복원은 독립 검증 후 확장한다. 보정값을 일괄 800ms로 올리거나 앞사람 이름을 전부 채우는 방식은 기본 전략으로 사용하지 않는다.
