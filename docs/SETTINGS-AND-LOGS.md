# 설정 저장과 오류 로그

초기 기록은 2026-09-24 개발본 기준이다. 현재 v0.2.0 기능의 설치·게시·검증 여부는 [릴리즈 기록](releases/v0.2.0.md)을 따른다. 아래 검증 절은 당시 실행 기록을 보존한다.

## 설정 저장·불러오기

상단의 **설정 및 오류 로그** 버튼에서 **설정 파일 저장**과 **설정 파일 불러오기**를 사용한다. JSON 백업에는 다음 항목이 포함된다.

- 앱 화면 언어.
- Whisper 모델, GPU/CPU 선호, 음성 언어(AUTO 포함), 화자 구분 여부, 짧은 단어 화자 보정 범위.
- VST 체인 전체 사용 여부, 처리 대상, 슬롯 순서·활성화, 플러그인 경로·이름, 수정한 매개변수.

분석 설정과 VST 설정은 변경할 때 이 기기에 자동 저장한다. 분석 창을 다시 열면 복원된다. GPU를 쓸 수 없을 때는 현재 분석에 CPU를 사용하되 저장한 GPU 선호는 유지한다. 미디어마다 다른 오디오 트랙 번호는 저장하지 않는다.

VST 영역의 **VST 설정 저장/불러오기**는 체인만 옮기는 별도 앱 프리셋이다. 제조사의 `.vstpreset` 파일이나 플러그인 내부의 숨겨진 상태 전체를 저장하는 기능은 아니다. 다른 PC에서는 플러그인을 설치하고 경로를 확인해야 한다.

백업을 불러오면 해당 설정을 대체하며, 설정 검증만으로 모델·플러그인을 실행하거나 다운로드하지 않는다. 파일 형식·버전·값을 전체 검증한 뒤 적용한다. 잘못된 파일은 현재 설정을 변경하지 않는다. 두 JSON 형식 모두 최대 2 MiB이며, 저장 공간 오류와 복원 실패를 화면에 알린다. 저장 실패 시 이전 값을 복원하려고 시도하며 저장소 자체가 계속 거부하면 복원 실패도 명시한다.

자막, 인물 이름·색상·스타일, 편집 메모, 컷 정보는 기존 **프로젝트 저장**으로 보관한다. 설정 백업에 음원, 자막 원문, 플러그인 바이너리는 포함하지 않는다. 자동 저장은 현재 앱/브라우저 프로필에 속하므로 별도 JSON 백업으로 기기 간에 옮길 수 있다.

## 오류 로그

**설정 및 오류 로그 → 오류 로그 저장**으로 화면과 서버의 최근 오류를 JSON 파일로 저장한다. **최근 오류 보기**에서 최근 10건을 확인할 수 있다. 기록에는 발생 시각, 발생 영역, 오류 종류, 메시지가 들어간다.

- 화면: API 연결·응답 실패, 처리하지 못한 화면 오류, 설정 가져오기/내보내기 실패. 최대 100건을 로컬 저장하고 같은 오류가 1분 내 이어지면 횟수로 묶는다. 저장소를 쓸 수 없으면 현재 세션에서만 보관하고 상태를 알린다.
- 서버: 분석·미디어 렌더·VST 검사/처리 실패, 서버 재시작으로 중단된 작업, 예상하지 못한 API 오류. 앱 데이터 폴더의 `logs/diagnostics.jsonl`에 기록하며 256 KiB씩 최대 3개 파일로 순환한다. 내보내기는 최근 최대 500건이다.
- 사용자가 취소한 작업과 일반적인 404 상태 조회는 오류 기록에서 제외한다.
- 서버가 연결되지 않아도 화면에서 수집한 로그만 내보낼 수 있다. 이 경우 서버 로그가 빠졌다는 상태를 파일과 화면에 표시한다.
- 로그에는 요청 본문, 음원, 자막 원문, 플러그인 매개변수, 스택 전체를 수집하지 않는다. 오류 메시지의 일반적인 경로·인증정보·이메일 패턴은 저장/내보내기 전에 가린다. 자동 외부 전송은 없다.

개발 실행의 서버 로그 위치는 `data/logs/`이고, 설치형에서는 `<userData>/data/logs/`이다. 앱 시작 전 실패와 네이티브 런처 출력은 기존 `<userData>/logs/backend.log`도 확인한다. 서버가 완전히 종료된 상태에서 해당 런처 파일을 앱 화면으로 가져오는 기능은 이번 범위에 없다.

## 검증

- 설정/VST JSON 왕복, 크기·버전·형식·값 검증, 손상된 저장소, 저장 실패 시 복원, 언어 설정 이전, GPU 선호 보존을 자동 검사했다.
- 오류 로그의 순환, 서버 재시작 후 유지, 동시 기록, 저장 실패 시 메모리 대체, 잘못된 기록 제외, 경로·인증정보 가림, 실제 실패/취소 경로를 자동 검사했다. Windows 심볼릭 링크 생성 권한이 없어 해당 회귀 검사 하나는 건너뛰었다.
- 실제 브라우저에서 설정을 파일로 저장한 뒤 다른 설정을 불러오고, 잘못된 파일을 거부한 뒤에도 설정이 유지됨을 확인했다. 분석 화면에 Large v3 Turbo·일본어·CPU·전사만·0.2초 보정 값이 복원됐다.
- VST 단독 JSON 저장/불러오기, 자동 저장 상태, 없는 플러그인의 실패 기록을 확인했다. 다운로드된 통합 로그 파일에서 실제 `vst/inspect_failed`와 `settings/import-failed` 항목을 확인했다.
- 새 설치본 제작·배포와 상용 방송 장시간 실행 검증은 수행하지 않았다.
