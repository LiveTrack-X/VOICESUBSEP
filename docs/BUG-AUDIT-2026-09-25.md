# Source audit / 소스 오류 감사 — 2026-09-25

This audit covers the working source after the local v0.2.1 checkpoint, including Advanced providers, audio mixing and document exports. It is **not an installer or release acceptance record**. The default is local **Whisper + Nemotron**. Translation and automatic AI meeting summaries were removed at the user's request; existing project fields remain readable for compatibility.

로컬 v0.2.1 확인본 이후의 현재 소스를 점검했습니다. **이번 결과는 새 설치 파일의 배포·설치 완료를 뜻하지 않습니다.** 기본 분석은 로컬 **Whisper + Nemotron**이며 다른 인식·화자 구분 공급자는 Advanced에 모았습니다. 번역·AI 회의 요약은 사용자 요청에 따라 제거했고 기존 프로젝트 데이터는 호환성을 위해 읽을 수 있도록 유지합니다.

## Confirmed fixes / 확인 후 수정한 오류

| Problem / 문제 | Correction and evidence / 수정 및 근거 |
| --- | --- |
| A large project could be saved with indentation beyond the reader's 8 MiB limit / 큰 프로젝트가 저장 후 다시 열리지 않음 | Validate the serialized project and use compact JSON when needed; a 20,000-caption boundary regression covers save/load / 직렬화 검증·필요시 압축 JSON 저장, 2만 자막 경계 테스트 |
| A damaged recovery backup warning disappeared on an unchanged save / 동일 내용 자동 저장으로 손상된 복구본 경고가 사라짐 | Preserve the warning while the same unreadable backup remains / 손상된 이전 복구본의 경고 유지 |
| A project containing only mixer settings could be replaced without warning / 믹서 설정만 있는 프로젝트가 확인 없이 교체됨 | Include mixer tracks in the unsaved-work guard; confirmed in the browser / 믹서 트랙도 작업 존재 판정에 포함, 화면 확인 |
| Array/number values passed string enum validation / 배열·숫자 값이 문자열 설정 검사 통과 | Strict string checks for analysis preferences and mixer format/frame rate; regression tests / 인식 설정·믹서 형식·프레임률의 타입 검사 강화 |
| Cancelling a cloud response could leave a Windows read blocked after the HTTP connection detached its socket / 클라우드 취소 후 Windows 응답 읽기가 남음 | Capture and close the detached response transport, then close the response; socket-pair regression / 분리된 응답 소켓을 먼저 닫고 응답 정리, 실제 소켓 회귀 테스트 |
| Adding `.pdf` after a save dialog could target an existing file without confirming the final path / PDF 확장자 추가 후 다른 기존 파일 덮어쓰기 가능 | Confirm the exact final filename with the native save dialog / 최종 파일명으로 저장 확인 |
| PDF export retained a document URL in a long-lived session, or stayed busy if cleanup failed / PDF 문서 URL 잔류·정리 실패 후 저장 불가 | Reuse one isolated in-memory session, release the request hook and always clear the busy flag / 격리 메모리 세션 재사용·문서 참조 해제·작업 상태 정리 |
| The analysis history called paid-provider jobs local analysis / 유료 인식 작업도 로컬 분석으로 표시 | Use a provider-neutral analysis label / 중립적인 음성 분석 표시 |
| Nemotron's eight-speaker warning appeared for another diarization provider / 다른 화자 모델에도 Nemotron 인원 제한 경고 | Apply the warning only to Nemotron / 해당 모델에만 제한 경고 |
| A VST preview shutdown exception skipped render-worker cleanup / VST 종료 오류가 렌더 작업 정리를 건너뜀 | Nested cleanup guarantees later workers are stopped; failure-injection regression / 예외 발생 시에도 뒤의 작업 종료 보장, 실패 주입 테스트 |
| Current documentation advertised unpublished v0.2.1 downloads / 미공개 버전을 공개 다운로드로 안내 | Separate public v0.2.0, locally installed v0.2.1 and current source / 공개·로컬 설치·현재 소스 상태 분리 |
| Qwen mock tests depended on locally installed optional libraries / Qwen 모의 테스트가 로컬 선택 라이브러리에 의존 | Mock generation-control and Hub transport boundaries as well as model loading; run without optional libraries / 모델 로딩뿐 아니라 생성 제어·Hub 전송 경계도 모의 처리해 선택 의존성 없는 환경에서 검증 |

## Verification / 검증

Automated checks are recorded in [machine-readable evidence](evidence/source-audit-2026-09-25.json). The backend skip is the Windows account's inability to create symbolic links. Vite's bundle-size warning and Starlette's AnyIO deprecation warning remain; neither is a test failure.

자동 테스트 수치는 [검증 기록](evidence/source-audit-2026-09-25.json)에 남깁니다. 백엔드 1건은 Windows 계정의 심볼릭 링크 생성 권한 때문에 건너뛰었습니다. Vite 번들 크기 경고와 Starlette의 AnyIO 사용 중단 예정 경고는 남아 있습니다.

The first GitHub run exposed nine Qwen mock-test failures because the minimal CI environment intentionally does not install Transformers or huggingface_hub. The follow-up fixes test isolation rather than adding model dependencies or skipping these cases. / 최초 GitHub 실행에서는 최소 CI 환경에 선택 라이브러리가 없어 Qwen 모의 테스트 9건이 실패했습니다. 후속 수정은 모델 의존성 추가나 테스트 생략 대신 모의 테스트의 독립성을 보완합니다.

The installed development Transformers package also logs an image-processor docstring diagnostic while importing engine classes. The tested health endpoint still returned 200; this upstream diagnostic was not suppressed or counted as a failed inference. / 개발용 Transformers의 엔진 import 중 이미지 처리기 docstring 진단 로그도 관찰했습니다. 시험한 health 응답은 200이었으며 이 외부 패키지 로그를 숨기거나 추론 실패로 판단하지 않았습니다.

Actual operations / 실제 동작 확인:

- Isolated localhost UI: default Whisper/Nemotron, Advanced Qwen/Gemini/Deepgram selection, separate cloud consent, missing-key blocking and restoring defaults. No paid calls or model downloads occurred. / 별도 테스트 화면에서 기본 조합·모델 선택·동의·키 미입력 차단·기본 복원 확인. 유료 호출·모델 다운로드 없음.
- At 518 × 778, captions remain editable, the timeline folds, and document width stays 518 px without horizontal overflow. A changed caption survived immediate reload. New project reset speaker names and undo history. / 좁은 창 자막 수정·자동 저장 복구·인물 이름과 실행 취소 초기화 확인.
- Real FFmpeg mixing of two synthetic six-second sources, with the second at −6 dB and +1.25 s, produced a 7.25-second, 48 kHz stereo WAV. / 합성 오디오 두 트랙의 음량·시간 이동을 적용한 실제 믹싱 출력 확인.
- Real hidden Electron PDF output: 27,071 bytes, one page; Korean speaker names, utterances and timestamps survived text extraction and a rendered-page visual check. / 실제 PDF 생성·한국어 텍스트 추출·페이지 렌더 확인.
- Six generated DOCX/XLSX documents passed ZIP CRC/XML/relationship checks. This does not claim native Word/Excel interoperability testing. The in-app browser's DOCX download event timed out, so successful browser download delivery is **not** claimed. / 문서 구조 검증과 브라우저 다운로드 전달 검증을 구분.
- No warning/error console entries appeared during the tested UI flows. Existing user projects and the user's running services were preserved. / 시험한 화면 흐름에서 콘솔 오류·경고 없음, 기존 사용자 데이터·서비스 유지.

## Remaining boundaries / 남은 검증·배포 범위

- Qwen is a **development-only option**. Its tokenizer dependency has inconsistent GPL/LGPL metadata, so the normal installer excludes this runtime and the opt-in packaging switch fails explicitly. Model weights and real GPU recognition quality were not tested here. See [Qwen runtime](QWEN-RUNTIME.md).
- Qwen은 **개발환경 전용**입니다. 토크나이저 의존성의 라이선스 표시 불일치가 해결되지 않아 일반 설치기에서 제외하며 강제 포함 빌드도 명시적으로 차단합니다. 이 감사에서 실모델 GPU 인식 품질은 확인하지 않았습니다.
- Paid-provider tests use controlled responses, not paid accounts. Real microphone/loopback devices, commercial VSTs, full GPU recognition, signing and update-feed distribution need separate validation. / 유료 계정·실제 녹음 장치·상용 VST·전체 GPU 분석·서명·업데이트 배포는 별도 검증 대상입니다.
- Public GitHub release: v0.2.0 prerelease. v0.2.1 is an unpublished draft with no assets, plus an older local installation checkpoint. This audit did not publish or install a new build. / 공개 배포본은 v0.2.0, v0.2.1은 자산 없는 초안 및 기존 로컬 설치 확인본입니다. 이번 변경의 설치·배포는 하지 않았습니다.

Unfinished product features, including live incremental recognition, native capture options and acoustic source separation, remain explicitly listed in [feature status](FEATURE-STATUS.md). Passing this audit does not establish absence of all defects.

실시간 점진 인식·네이티브 녹음 선택지·섞인 음성의 실제 분리 등 미완료 기능은 [기능 현황](FEATURE-STATUS.md)에 구분합니다. 감사 통과가 모든 결함의 부재를 보장하지는 않습니다.
