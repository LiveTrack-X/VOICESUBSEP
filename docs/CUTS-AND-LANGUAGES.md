# 컷편집·다국어: 현재 소스 구현 계약

초기 기록: 2026-09-24. v0.2.0의 설치·게시·검증 여부는 [릴리즈 기록](releases/v0.2.0.md)을 따른다. 아래는 컷·번역의 저장·처리 계약이며, 확장된 편집·OBS 트랙·문서·녹음은 [현재 편집 워크플로](EDITING-WORKFLOWS.md)에 정리한다. 이전 [확장 계획](EXPANSION-ROADMAP.md)은 역사적 제안이다.

## 세 가지 언어 설정

| 설정 | 현재 범위 | 다른 설정에 미치는 영향 |
| --- | --- | --- |
| 앱 표시 언어 | 한국어·영어·일본어·중국어 간체·스페인어 | 브라우저에 저장하고 HTML `lang`도 변경. 원문·인물 이름·메모는 번역하지 않음 |
| 음성 인식 언어 | 기본 자동 감지, Whisper 언어 코드 100개 수동 선택 | 별도로 기억하며 표시 언어와 독립. 지원 코드 목록은 모든 언어의 동일한 정확도를 뜻하지 않음 |
| 자막 번역 언어 | 한국어·영어·일본어·중국어 간체·스페인어 | 원문 옆의 별도 번역 데이터. 원래 음성·단어 시간은 유지 |

표시 언어와 음성 언어는 각각 `voicesubsep-ui-locale`, `voicesubsep-asr-language`에 저장한다. 프로젝트가 다시 열릴 때 번역은 프로젝트 JSON에서 복원한다. 메뉴를 영어로 바꿨다고 한국어 음성이 영어 음성으로 분석되지는 않는다.

## 컷 지정·미리보기·복원

‘간단한 컷편집’에서 시작·끝을 입력하거나 현재 재생 위치로 잡고 **구간 제외**를 누른다. 선택 자막의 발화 구간도 제외할 수 있다. 타임라인에 제외 구간을 표시하며 개별 복원, 전체 복원, 실행 취소·다시 실행을 지원한다. 원본 파일은 덮어쓰지 않는다.

편집본 미리보기는 제외된 원본 구간을 건너뛰고 편집 후 재생 시간을 표시한다. 자막·메모를 편집하는 좌표와 타임라인은 원본 초 단위를 유지한다. 브라우저 재생 위치를 옮기는 미리보기이므로 **프레임·샘플 단위의 최종 출력 검증을 대신하지 않는다.**

저장 계약은 다음과 같다.

- v1 JSON은 기존 형태로 읽는다. 컷을 추가한 프로젝트는 `schemaVersion: 2`, `cuts: [{id,start,end}]`로 저장한다. v2는 빈 배열을 포함해 `cuts`가 필요하다.
- 자막·메모·컷 시간은 원본 초 단위다. 매핑 계산은 정수 마이크로초로 반올림해 수행하고, 출력 시각은 파생 값으로 만든다.
- 컷은 최대 200개이며 렌더에 전달할 **유지 구간도 최대 200개**다. 내부 컷 200개가 유지 구간 201개를 만드는 경우에는 추가를 허용하지 않는다. 중첩 컷의 합집합은 계산할 때 구하며, 복원을 위해 저장된 개별 컷은 유지한다.
- 전체 삭제 상태는 데이터 계산으로 표현할 수 있으나 UI에서는 내보낼 구간을 남기게 하며 빈 렌더 요청은 거부한다.

자막이 컷을 가로지르면 현재 원문과 일치하는 단어 시간으로 남은 부분을 나눈다. 단어를 자르거나 단어 시간이 없거나 오래된 원문을 가리키면 검수 대상으로 남기고 **편집본 SRT를 차단하며 해당 자막을 편집본 미리보기에서 숨긴다.** 원본 편집기에서는 계속 확인할 수 있다. 완전히 제외된 자막은 파생 결과에서만 빠진다.

범위 메모는 남은 구간마다 나뉘고, 삭제된 점 메모·범위 메모는 편집본에서 제외된 개수로 알린다. 원본 메모의 내용·상태를 변경하지 않는다. 분할된 자막의 문장이 달라지면 기존 번역을 승계하지 않는다. 번역된 편집본이 필요하면 **원본 편집기에서 컷 경계를 넘지 않게 자막을 나누고 문구·시간을 확정한 다음 다시 번역**한다. 번역 결과를 원래 단어 시간에 억지로 대응시키지 않는다.

원본 재연결은 파일명과 재생 길이를 확인하며, **전체 파일 해시로 동일성을 검증하지 않는다.** 이름·길이가 같은 다른 파일까지 판별할 수 없으므로 실제 같은 원본인지 확인해야 한다. 저장된 컷과 재연결 길이가 충돌하면 재생 메타데이터가 프로젝트 길이를 덮어쓰지 않도록 막는다. SRT를 가져와도 이미 연결된 미디어의 길이를 자막 마지막 시각으로 늘리지 않는다.

## 실제 편집본 내보내기

내보내기 창을 열 때 프로젝트 사본을 고정하여, 비동기 렌더와 자막·메모 파일이 같은 편집 상태를 사용한다. 원본의 **오디오 트랙 하나**를 선택한다. 여러 트랙의 혼합이나 화자별 음원 분리는 포함하지 않는다.

| 출력 | 고정 처리 | 자막·메모 시간 기준 |
| --- | --- | --- |
| MP4 | H.264, 원본 프레임률·30·60fps 중 선택한 고정 프레임률, AAC 48 kHz 스테레오 | 선택한 프레임률의 실제 프레임 경계에 정렬된 유지 구간 |
| WAV | PCM 16비트, 48 kHz 스테레오 | 실제 1/48000초 샘플 경계에 정렬된 유지 구간 |
| MP3 / M4A | MP3 / AAC, 48 kHz 스테레오 | 같은 샘플 경계. 압축 형식의 패딩은 별도 경고 |

렌더러가 반환한 `keepRanges`가 최종 경계의 기준이다. 화면에 입력한 소수 초를 그대로 믿고 SRT를 만들지 않는다. 완료 창에서 출력 파일과 이 경계에 맞춘 **편집본 SRT·메모 CSV**를 저장한다. 컷 경계 검수나 번역 누락이 있으면 해당 SRT 저장을 허용하지 않는다. 일반 SRT는 스타일을 포함하지 않으며 자막을 영상에 입혀 굽는 기능도 이 범위에 포함하지 않는다.

`원본` 프레임률도 탐지한 소스 프레임률로 고정 프레임률 재인코딩하며 가변 프레임률을 그대로 보존하지 않는다. 프레임률을 확인할 수 없으면 30 또는 60을 선택해야 한다. 작업 이력에서 다시 여는 렌더의 자막·메모는 렌더 시작 시점의 저장된 프로젝트 스냅샷을 사용한다.

렌더는 유지 구간을 순차 처리하며 FFmpeg의 영상 인코딩 스레드는 2개로 제한한다. 임시 NUT/WAV 구간을 디스크에 만들고 이어 붙인 뒤 최종 오디오를 한 번 인코딩한다. 메모리 절약 구조이지만 임시 디스크 사용량은 출력 길이에 비례한다. 완성 길이·영상 여부·프레임 수를 검증한 뒤 임시 파일을 최종 파일로 원자적으로 전환한다. 취소 시 소유한 FFmpeg 프로세스를 종료·회수하며 원본을 보존한다. 서버 재시작 후 중단된 렌더를 자동 재개하지 않는다.

## 로컬 자막 번역

번역에는 **이 PC에서 별도로 설치·실행한 Ollama와 준비된 텍스트 모델**이 필요하다. 앱이 Ollama를 자동 시작하거나 모델을 pull하지 않는다. `127.0.0.1:11434`만 호출하며 환경 변수의 원격 주소·프록시를 사용하지 않는다. 모델 목록과 상세 정보에서 알려진 클라우드·원격 모델을 먼저 거부한다. 이는 앱의 호출 경로와 모델 확인 규칙이며, 외부 프로세스·네트워크까지 격리한다는 보장은 아니다.

‘자동 · 로컬 GPU 우선’ 또는 ‘CPU만 사용’을 고른다. 실제 GPU 사용 여부와 번역 품질은 준비된 Ollama·모델·장치에 달려 있다. 기본적으로 해당 언어 번역이 없거나 원문이 바뀐 자막만 처리하고, 전체 재번역도 선택할 수 있다.

요청은 순차적으로 최대 8개 자막·UTF-16 기준 12,000자를 묶는다. 원문 한 자막은 10,000자, 번역은 8,000자까지다. ‘현재 묶음 완료 후 중지’는 진행 중인 추론을 즉시 중단하지 않는다. 완료된 일부 결과를 원문과 비교하고 수정한 뒤 한 번에 적용하며, 한 번의 실행 취소로 되돌릴 수 있다. 적용 전 프로젝트는 바뀌지 않는다.

번역에는 `sourceText`와 언어별 문구를 저장한다. 적용 시 자막 ID와 현재 원문이 일치하는 결과만 반영한다. 원문을 수정하면 이전 번역은 유효하지 않게 되고, 미리보기는 원문으로 돌아간다. 번역 SRT는 선택 대상의 번역이 없거나 오래됐으면 차단한다. 내보내기 사본에서는 원래 단어 시간과 번역 메타데이터를 제거하여 번역 단어의 시간인 것처럼 사용하지 않는다.

관련 API는 `/api/translation/status`, `/api/translation/batch`, `/api/renders`, `/api/renders/{id}`와 완료 미디어 경로다. 번역 결과의 ID·원문·언어·모델·개수가 맞지 않거나 잘린 JSON이면 적용하지 않는다. 렌더의 실제 경계 변환은 `src/render.ts`, 컷 계산은 `src/cuts.ts`, 번역 적용·유효성은 `src/translation.ts`에서 담당한다.

## 검증 기록의 범위

아래는 2026-09-24 당시의 실행 기록이다. v0.2.0의 새 자동 검사·번들·설치 검증은 [버전별 기록](releases/v0.2.0.md#검증-기록)을 확인한다.

- 실제 로컬 실행: 설치된 `gemma4:e4b`를 **CPU로 실행한 한국어→영어 자막 1건**과 브라우저에서 추가 3건의 번역·검토·적용을 확인했다. 저장한 JSON에서 원문·시간·화자를 보존하고 번역을 별도로 저장했다. 다섯 언어의 품질, 긴 자막, 스트리머 고유명사 정확도를 검증한 것은 아니다.
- 통합 자동 테스트·빌드: `npm test`의 프런트엔드 **150개**, 데스크톱·실행기 **34개** 통과, `npm run build` 성공. 백엔드 전체 **365개** 통과 후 마지막 RF64 출력 옵션 변경은 렌더 집중 **51개**로 재검증했다. 합성 파일 검증에는 WAV·MP3·M4A·MP4, 지연된 트랙·공백·짧은 영상, 취소·오류 정리가 포함된다.
- 브라우저 통합 QA: 기존 작업과 다른 localhost 저장소에서 5개 화면 언어 전환과 문서 언어 속성, AUTO 기본값, 일본어 직접 선택 후 재열기 유지, 컷 추가·타임라인 표시·편집본 재생을 확인했다. 같은 이름의 짧은 원본을 연결하면 미디어 연결이 해제되고 기존 6초 길이·컷이 유지됨을 확인했다.
- 실제 출력: 6초 합성 음성에서 2–3초를 제외하여 **5.000000초, PCM 16비트, 48 kHz stereo WAV**를 생성했다. 브라우저에서 저장한 SRT는 삭제 자막을 제외하고 원본 4–5초 자막을 3–4초로 옮겼다. 메모 CSV도 삭제 구간의 점 메모를 제외하고 남은 메모를 4초→3초로 매핑했다. 영어 번역 SRT도 같은 시각과 `Hello.` / `Thank you.`를 확인했다. 장시간·4K·200구간의 실제 성능은 검증하지 않았다.
- 설치 파일 재생성·설치본 동작·배포: 이 문서의 완료 범위에 포함하지 않는다.

현재 VST 전처리는 [VST 체인](VST-CHAIN.md), 인터뷰·회의록과 종료 후 분석용 녹음은 [편집 워크플로](EDITING-WORKFLOWS.md)를 따른다. 최종 다중 트랙 믹스·스트리밍 ASR·무음 후보 자동 탐색 등 후속 제안은 [음성 전처리 제안](AUDIO-PREPROCESSING.md), [확장 계획](EXPANSION-ROADMAP.md), [라이브 설계](LIVE-CAPTURE-PLAN.md)에 보존한다.
