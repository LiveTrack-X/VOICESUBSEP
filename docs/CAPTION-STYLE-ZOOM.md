# Caption styling and detailed timeline / 자막 스타일·타임라인 정밀 편집

0.3.6 대상 기능입니다. 기존 인물별·자막별 스타일 설정을 확장했습니다. 패키지·게시·설치 검증 상태는 [0.3.6 릴리즈 기록](releases/v0.3.6.md)을 따릅니다.

검증 범위와 결과는 [소스 검증 기록](evidence/caption-style-zoom-source-validation.json)에 정리했습니다. 프런트 테스트 1,007개, 데스크톱·개발 스크립트 테스트 88개, 웹 빌드, 실제 앱 화면·저장 동작, 로컬 ASS 렌더를 확인했습니다.

## 스타일 설정 위치

- 인물 목록의 팔레트 버튼: 해당 인물의 기본 자막 스타일을 설정합니다.
- 자막의 스타일 버튼: 해당 자막 한 개에 필요한 항목만 덮어씁니다. 지정하지 않은 값은 인물의 기본 스타일을 따릅니다.
- 미리보기로 확인하고 **적용**합니다. **취소**는 프로젝트를 바꾸지 않습니다. 초기화 후 적용하면 인물 스타일 또는 앱 기본값으로 돌아갑니다. 변경은 기존 실행 취소와 자동 저장을 사용합니다.

## 글꼴·획·그림자

| 항목 | 설정 |
| --- | --- |
| 글꼴 이름 | PC에 설치된 글꼴 이름 하나를 입력하거나 목록에서 선택합니다. Windows 설치형의 **설치 글꼴 불러오기**는 실제 설치된 글꼴 이름을 읽습니다. |
| 기본 글꼴 | 지정한 글꼴이 없을 때 고딕·명조·고정폭 중 대체할 종류를 선택합니다. **기본 글꼴 사용**은 직접 지정한 이름을 비웁니다. |
| 글자 테두리 | 켜기/끄기, 두께 0~8px, 색상을 지정합니다. 색상을 직접 지정하지 않은 기존 자막은 자동 대비색을 유지합니다. |
| 글자 그림자 | 켜기/끄기, 색상, 흐림 0~12px, 가로·세로 거리 -12~12px를 지정합니다. 음수 거리는 왼쪽·위쪽입니다. |

실제 자막 미리보기에서 글꼴·테두리·그림자가 함께 표시됩니다. 그림자 흐림은 본문 글자를 흐리게 만들지 않으며 인물 이름 배지의 가독성은 유지합니다.

글꼴 파일을 다운로드하거나 프로젝트·자막 파일에 포함하지 않습니다. 다른 PC에서도 같은 글꼴로 보려면 해당 PC에 같은 글꼴이 있어야 합니다. 브라우저에서는 이름 직접 입력을 지원합니다. 설치형의 목록은 앱 실행 중 캐시하며 새로 설치한 글꼴은 앱을 다시 실행한 뒤 불러오세요.

프로젝트에는 선택한 이름과 스타일 값만 저장합니다. 새 스타일 필드가 들어간 프로젝트는 이전 앱에서 읽지 못할 수 있습니다. 새 앱은 기존 스타일이 없는 프로젝트와 기존 고딕·명조·고정폭 설정을 계속 읽습니다.

## 출력 형식

| 형식 | 반영 범위 |
| --- | --- |
| 프로젝트 JSON | 글꼴 이름과 테두리·그림자 설정, 부분 상속을 저장합니다. |
| ASS | 글꼴 이름, 획 두께·색상, 별도 그림자 레이어의 색상·흐림·거리를 반영합니다. 렌더러별 글꼴 대체·줄바꿈 차이는 남습니다. |
| SRT | 기존대로 글자와 시간만 저장합니다. 글꼴·획·그림자는 포함하지 않습니다. |
| YTT | 지원하는 기본 글꼴 종류와 네이티브 가장자리 효과로 근사합니다. 실제 글꼴 이름, 정확한 획 두께, 그림자 흐림·거리, 획과 그림자의 동시 표현은 보존하지 못합니다. 두 효과를 켜면 획을 우선합니다. |

ASS는 기존과 같은 1920×1080 기준 좌표를 사용합니다. 미리보기의 CSS px 설정을 기준 배율로 변환하므로 모든 플레이어와의 픽셀 일치를 보장하지 않습니다. 합성 한글·영문 자막의 실제 FFmpeg/libass 렌더에서 글꼴 선택·획·흐린 그림자·자막 시작/끝을 확인했습니다. YTT의 실제 YouTube 수용·표시는 [기존 제한](YOUTUBE-CAPTIONS.md)을 따릅니다.

## 64× 타임라인

확대 비율은 **1·2·4·8·16·32·64×**입니다. `+`/`-` 버튼 또는 비율 선택 목록으로 바꿉니다. 현재 재생 위치가 보이면 그 위치를 화면의 같은 지점에 유지하고, 재생 위치가 밖에 있으면 보고 있던 구간의 중심을 유지합니다.

확대하면 눈금이 추가되며 필요한 곳에 밀리초를 표시합니다. 많은 자막의 밀도 그림은 계속 보이는 영역 크기로만 그립니다. 확대는 원본 시간·자막 값·오디오를 바꾸지 않으며 새로운 프레임 스냅이나 자동 음성 정렬을 추가하는 기능은 아닙니다.
