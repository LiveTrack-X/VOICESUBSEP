# v0.3.4 — Editing workspace and reconnection / 편집 화면·원본 재연결

**Release preparation — not published or installed yet.** The changes below are
implemented in the frozen 0.3.4 source and final source regression passed.
Installer packaging and release verification are still in progress. The current
public release remains [0.3.3](v0.3.3.md); this page does not establish a completed upgrade.

**릴리즈 준비 중 — 아직 미게시·미설치입니다.** 0.3.4 소스는 동결했고 최종 소스
회귀 검사를 통과했습니다. 설치 파일 제작·배포 검증은 진행 중이며, 현재 공개 버전은 [0.3.3](v0.3.3.md)입니다. 이 기록은 업데이트 설치 완료를 의미하지 않습니다.

## Changes / 변경 사항

- **Independent panel and column widths.** Drag the right edge of project settings
  or the preview/cut panel to resize each separately. Caption time and speaker
  columns also resize independently; subtitle text uses the remaining width.
  Keyboard arrows/Home/End and reset controls are available. Preferences persist
  on this device; temporary viewport clamps do not overwrite them. Narrow
  workspaces retain their stacked layout.
  / **패널·열 너비 개별 조절:** 프로젝트 설정과 미리보기·컷 패널의 오른쪽 경계를
  각각 드래그합니다. 자막 표의 시간·인물 열도 따로 조절하며 자막은 나머지 폭을
  사용합니다. 방향키·Home/End·기본값 복원과 기기별 저장을 지원하고, 좁은 창의
  임시 제한이 저장한 폭을 덮어쓰지 않습니다. 좁은 화면에서는 세로 배치를 유지합니다.
- **Automatic video fit.** Preview uses the largest uncropped, aspect-preserving
  size that fits its measured width and available height after controls, cuts and
  notes. The old height slider and stored manual height no longer constrain it.
  Collapse, playback and fullscreen remain. Letterboxing already encoded in the
  original is not removed.
  / **영상 자동 맞춤:** 재생 조작·컷·메모가 차지한 공간을 뺀 실제 가로·세로 안에서
  원본 비율을 유지하며 최대 크기로 표시합니다. 이전 높이 슬라이더와 저장된 수동
  높이 제한은 적용하지 않습니다. 접기·재생·전체 화면은 유지하며 원본에 들어 있는
  검은 여백을 자르거나 영상을 늘리지 않습니다.
- **Usable notes.** Resize the notes panel vertically, retain that preference, and
  edit start/end times as seconds or timecodes. Set either boundary to the current
  playback position. Cards adapt to panel width, an empty panel stays compact,
  and explicitly opening a timeline note reveals its editor.
  / **메모 조작 개선:** 메모 패널 높이를 조절·저장하고 시작·종료를 초 또는 시간
  코드로 입력합니다. 현재 재생 위치를 시작·종료로 넣을 수 있습니다. 폭에 따라
  카드 배치를 바꾸고 빈 메모는 작게 표시하며 타임라인에서 편집을 열면 해당 메모를
  보여 줍니다.
- **Desktop original-media reconnection.** After a file is explicitly selected,
  the desktop app remembers its location privately on this device. Reopening its
  project verifies the original's SHA256 and byte count, then reuses a verified
  local media cache or streams a replacement upload to the local backend.
  Missing or changed originals require manual reconnection. Checking, connected
  and disconnected states have text/icons as well as color.
  / **설치형 원본 자동 재연결:** 직접 선택한 파일 위치를 이 기기에 별도로 기억합니다.
  프로젝트를 다시 열면 원본의 SHA256·크기를 확인한 뒤 검증된 로컬 캐시를 재사용하거나
  로컬 서버로 다시 스트리밍합니다. 파일이 없어졌거나 내용이 다르면 수동 재연결을
  안내합니다. 확인 중·연결됨·미연결은 색뿐 아니라 아이콘과 글자로 구분합니다.
- **Protect connected media during cache cleanup.** The cache list marks the
  currently connected desktop media as protected, excludes it from reclaimable
  space, and disables both individual and bulk deletion. Confirmations are
  rechecked against the current connection and refreshed cache list before
  submitting; files newly uploaded after the reviewed selection are not added
  to that cleanup.
  / **연결된 캐시 삭제 보호:** 현재 편집기에 연결된 설치형 미디어를 보호 표시하고
  정리 가능 용량에서 제외하며 단건·일괄 삭제를 막습니다. 확인 창을 연 뒤 원본 연결이나
  캐시 목록이 바뀌어도 전송 직전에 다시 검사합니다. 확인 대상으로 보지 않은 새 업로드를
  일괄 정리에 추가하지 않습니다.
- **Timeline item menu.** Right-click a caption or note, or use Shift+F10, to open
  its editor, seek, move it to the playback position, or delete it. Moving preserves
  duration and clamps to media boundaries; project edits use existing undo.
  Opening the menu or editor does not itself start playback.
  / **타임라인 항목 메뉴:** 자막·메모에서 우클릭 또는 Shift+F10으로 편집 열기,
  해당 시점 이동, 현재 위치로 옮기기, 삭제를 선택합니다. 옮기기는 길이·미디어 끝
  경계를 지키며 변경은 실행 취소할 수 있습니다. 메뉴나 편집기를 여는 것만으로
  재생하지 않습니다.
- **Sharper dense timelines.** Dense lanes draw only the visible area and a small
  margin at the display's pixel ratio, instead of stretching a capped bitmap
  across the whole zoomed timeline. Horizontal scrolling, click targeting and
  context menus retain their position; clicking a dense lane no longer jumps the
  scroll before computing the selected time.
  / **밀집 타임라인 선명도·클릭 수정:** 확대된 전체 폭에 작은 비트맵을 늘리는 대신
  보이는 구간과 짧은 여유 영역만 화면 배율에 맞춰 그립니다. 가로 스크롤·클릭·메뉴
  위치를 유지하며, 클릭 순간 스크롤이 왼쪽으로 이동해 엉뚱한 시간을 선택하던
  문제를 수정했습니다.
- **Stable progress panels.** Queue controls and job details now have distinct
  sibling keys. Repeated polling no longer accumulates duplicate controls or
  resets a pending confirmation; changing jobs still resets the correct state.
  / **진행창 중복 방지:** 대기열 조작과 작업 상세의 내부 키를 분리했습니다. 반복
  상태 확인 때 조작 영역이 쌓이거나 확인 화면이 초기화되는 문제를 수정하며,
  다른 작업으로 전환할 때 필요한 상태 초기화는 유지합니다.
- **Visible VST actions and stale-preview cleanup.** Changing the input media,
  track or chain invalidates its comparison request and releases the preview
  lock. Late responses cannot overwrite a newer comparison/editor. Native editor
  progress and errors appear beside the clicked slot; a pre-request snapshot
  failure is shown rather than becoming an unhandled click.
  / **VST 무반응 경로 수정·즉시 표시:** 비교 생성 중 원본·트랙·체인이 바뀌면 이전
  비교 요청과 잠금을 정리합니다. 늦은 응답은 새 비교·설정창을 덮어쓰지 않습니다.
  클릭한 슬롯 옆에 전용 창 진행 상태·오류를 표시하고, 요청 준비 중 오류도 화면에
  알립니다. 사용자 설치본에서 발생한 모든 무반응의 원인을 확정한 것은 아닙니다.

- **Creator links.** The header logo and “Created by LiveTrack” footer open the
  creator's [GitHub profile](https://github.com/LiveTrack-X).
  / **제작자 링크:** 상단 로고와 하단 “Created by LiveTrack”에서 제작자 GitHub
  프로필을 열 수 있습니다.

## Limits and next work / 한계·다음 작업

Automatic original reconnection is **desktop-only and device-local**. It does not
restore a browser `File` after page reload, search the disk for moved files, embed
absolute paths in portable project exports, or guarantee access after a drive or
permission change. Old projects with no remembered location need one explicit
reconnection. Large files require a streamed hash check and may take time. The
service integration passed with temporary fixtures; the complete native file
selection, app restart and restored-playback UI path has not yet been verified.

원본 자동 연결은 **설치형 앱·같은 기기** 범위입니다. 브라우저 새로고침 후 `File`
복원, 이동한 파일의 디스크 검색, 프로젝트 내보내기에 절대 경로 포함, 드라이브·권한
변경 후 접근 보장은 제공하지 않습니다. 위치 기록이 없는 기존 프로젝트는 한 번
직접 연결해야 하며, 큰 파일의 스트리밍 해시 확인에는 시간이 걸릴 수 있습니다.
임시 합성 파일의 서비스 통합 검사는 통과했지만 네이티브 파일 선택→앱 재시작→자동
재연결 재생의 전체 UI 경로는 아직 검증하지 않았습니다.

Connected-media cache protection applies to this app's cleanup UI. It does not
introduce a server-side playback lease: another API client or app instance can
still delete a cache entry that the backend otherwise considers unused. No real
user cache or project was deleted during verification.

연결 미디어 보호는 이 앱의 캐시 정리 UI 범위입니다. 재생 중인 파일을 서버에서 모든
클라이언트에 걸쳐 예약하는 기능은 아니므로, 다른 API 클라이언트나 앱 인스턴스가
서버 기준으로 미사용인 캐시를 삭제하는 것까지 막지 않습니다. 검증 중 실제 사용자
캐시나 프로젝트를 삭제하지 않았습니다.

This release does not introduce a new speaker-assignment model or claim fewer
unassigned cues or better recognition accuracy. The
[speaker-assignment strategy](../SPEAKER-ASSIGNMENT-STRATEGY.md) is a **proposal**,
not an implemented algorithm. Existing Whisper/Nemotron, overlap and review
limitations remain. Subtitle translation and AI/Ollama meeting summaries remain
removed. Native VST support still depends on separately installed compatible
plugins and their licenses.

새 화자 배정 모델, 미배정 감소, 인식률 향상을 이번 변경의 성과로 주장하지 않습니다.
[미배정 감소 전략](../SPEAKER-ASSIGNMENT-STRATEGY.md)은 **제안**이며 알고리즘에 아직
적용하지 않았습니다. 기존 인식·동시 발화·검수 한계와 번역·AI/Ollama 자동 요약 제거는
유지합니다. 전용 VST 창은 별도 설치된 호환 플러그인·라이선스가 필요합니다.
