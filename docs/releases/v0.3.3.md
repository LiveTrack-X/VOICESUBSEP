# VOICESUBSEP 0.3.3 — Release preparation / 릴리즈 준비

**Implemented in source; publication and installation are pending.** The public
download remains [v0.3.2](v0.3.2.md). This draft does not establish a final release
commit, artifact hashes, CI acceptance or a completed installer upgrade. Those
checks are in progress and will be recorded separately. The published 0.3.2
release, tag and evidence are preserved.

**소스 구현을 마쳤으며 게시와 설치는 아직 진행 전입니다.** 현재 공개 다운로드는
[v0.3.2](v0.3.2.md)입니다. 이 초안은 최종 릴리즈 커밋·파일 해시·CI·설치 완료를
뜻하지 않습니다. 해당 검증은 진행 중이며 별도로 기록합니다. 공개 0.3.2 릴리즈·태그·
당시 증거는 보존합니다.

## Limits and compatibility / 한계와 호환

Preprocessing remains file-analysis/preview only: it does not modify originals,
final-render audio or live capture. Denoising may damage quiet speech, laughter
or overlapping voices; listening improvements do not establish ASR accuracy.
Real user microphones/interfaces, long recordings and all VST products have not
been accepted by these tests. Commercial plugins remain separately installed
and licensed. Opaque VST state may contain sensitive vendor data; review settings
backups before sharing. Older versions may not accept new RNNoise/state settings;
retain a pre-upgrade settings backup if rollback is needed.

전처리는 파일 분석·비교용이며 원본·최종 렌더·라이브 음원을 바꾸지 않습니다. 작은
발화·웃음·겹친 말을 손상할 수 있고 듣기 개선이 인식률 향상을 입증하지 않습니다.
실사용 마이크·오인페·장시간 녹음·모든 VST 제품의 수용 검증은 남아 있습니다. 상용
플러그인은 별도 설치·라이선스가 필요하고 내부 상태에 민감한 제조사 정보가 들어갈 수
있으므로 설정 백업 공유 전 확인하세요. 옛 버전이 새 RNNoise/상태 설정을 읽지 못할 수
있으므로 복귀가 필요하면 업그레이드 전 설정을 보관합니다.

Subtitle translation and automatic AI/Ollama summaries remain removed. Default
analysis remains local Whisper + Nemotron. Whisper/Nemotron weights are separate;
the small RNNoise model and existing Silero VAD assets do not change that policy.
Windows code-signing status and final artifact identity must be reported with
the eventual release evidence, not assumed from an updater manifest signature.

The speech-activity check does not blacklist phrases such as “thank you”, rewrite
recognized text, relabel speakers or modify previous results. It uses bounded
audio windows and fails open if evidence is unavailable. Very quiet speech or
laughter can still be misclassified, and hallucinations at speech boundaries may
remain as review items. Unit tests and one source-window diagnosis do not prove
an overall recognition-accuracy improvement.

사용자 결정으로 제거한 자막 번역·AI/Ollama 자동 요약은 복원하지 않습니다. 기본 분석은
로컬 Whisper+Nemotron입니다. Whisper/Nemotron 가중치는 별도이며 작은 RNNoise 모델과
기존 Silero VAD 포함이 그 정책을 바꾸지 않습니다. Windows 코드 서명 상태·최종 파일
식별 정보는 실제 릴리즈 증거에서 확인하며 업데이트 명세 서명으로 추정하지 않습니다.

음성 활동 검사는 ‘감사합니다’ 같은 문구를 금지하거나 원문·화자를 바꾸지 않으며 이전
결과를 자동 수정하지 않습니다. 제한된 길이의 오디오 창을 사용하고 근거를 읽지 못하면
대사를 보존합니다. 매우 작은 발화·웃음을 잘못 판단할 수 있고, 발화 경계의 오인식은
검수 대상으로 남을 수 있습니다. 회귀 검사와 일부 원본 구간 진단은 전체 인식률 향상을
입증하지 않습니다.
