## Changes / 변경 사항

- **Local fonts, outlines and shadows.** Choose a font installed on this PC by name; the Windows app can explicitly load the installed-family list. Set outline width/color and separate shadow color, blur and horizontal/vertical distance per speaker or caption. Apply, reset, cancel, undo and autosave use the existing project workflow. Project JSON/ASS preserve the settings; SRT remains text/timing only and YTT uses its documented limited approximations. Font files are not embedded. / **글꼴·획·그림자:** PC 글꼴 이름 입력·설치형 목록 불러오기, 인물별·자막별 획 두께/색상과 그림자 색상/흐림/가로·세로 거리, 적용·초기화·취소·실행 취소·자동 저장을 지원합니다. 프로젝트·ASS에 설정을 보존하며 SRT는 글자/시간만, YTT는 제한 근사입니다. 글꼴 파일은 포함하지 않습니다.
- **Timeline through 64×.** The ratio picker and ± buttons now offer 1, 2, 4, 8, 16, 32 and 64×. Zoom preserves a visible playhead's screen position or the source-time center of the viewed interval. Ruler labels include milliseconds when needed; density drawing stays bounded to the viewport plus limited overscan. Narrow headers wrap so controls remain reachable. / **최대 64배 확대:** 목록·버튼으로 1·2·4·8·16·32·64배를 선택합니다. 보이는 재생 위치 또는 보고 있던 원본 구간 중심을 유지하고 필요한 눈금에 밀리초를 표시합니다. 밀도 그림은 화면과 제한 여유 범위만 그리며 좁은 창의 상단 버튼도 줄바꿈해 유지합니다.
- **Flexible caption split and merge.** Preview a text-cursor or playback-time split and adjust the split time. Use aligned word times when still valid or an explicit proportional estimate otherwise. Merge adjacent or consecutively selected captions with automatic/extra spaces, newlines or direct joining; choose the resulting speaker explicitly when identities differ. Preserve text whitespace and the first caption's style, show gaps/overlap, reject stale/hidden-intervening targets, and undo the operation together. / **유연한 나누기·합치기:** 커서·재생 시점 분할 미리보기와 시간 조절, 유효한 단어 시각 또는 명시적 추정, 연속 자막의 공백/줄바꿈/붙이기와 다른 인물 직접 선택을 지원합니다. 원문 공백·첫 자막 스타일을 유지하고 시간 간격/겹침을 표시하며 오래된 미리보기·숨겨진 중간 항목을 보호하고 한 번에 실행 취소합니다.
- **Project vocabulary.** Save proper names and game terms with each project. Supported local/cloud engines receive validated hints; unsaved/invalid changes block analysis, queued jobs keep their saved snapshot, and changing cloud hints resets transmission consent. Existing captions are not automatically rewritten. / **프로젝트 사전:** 고유명사·게임 용어를 프로젝트에 저장하고 지원 엔진에 검증한 힌트를 전달합니다. 미저장/잘못된 입력은 분석을 막고 대기 작업은 당시 저장값을 사용하며 클라우드 힌트 변경은 전송 동의를 해제합니다. 기존 자막을 자동 치환하지 않습니다.
- **Confirmed-voice candidates — beta.** Register listened-to, reviewed solo references, compare unassigned solo captions against at least two speakers, then explicitly apply selected suggestions. Manual/reviewed/overlapping or uncertain targets remain protected; text/timing stay unchanged and undo is available. Cosine values and margins are experimental similarity policy, not calibrated probabilities or real-person identification. / **확인한 목소리 후보 — 베타:** 직접 듣고 검수한 단독 발화를 기준으로 두 인물 이상과 미배정 단독 자막을 비교한 뒤 선택 적용합니다. 수동/검수/겹침·불확실 대상은 보호하고 원문·시간과 실행 취소를 유지합니다. 유사도와 차이는 실험 기준이며 보정된 확률·실명 식별이 아닙니다.
- **Selected-window separation/retranscription — experimental.** Process only a chosen 2–20-second range locally on CPU using a two-source, 8 kHz English-trained SepFormer and cached Whisper. Listen to the original and candidates, choose text/speaker, and add selected candidates while keeping the old captions. Stop/discard/undo and source snapshot checks remain explicit. / **선택 구간 분리·재전사 — 실험:** 2~20초 구간만 로컬 CPU·2인·8kHz 영어 학습 SepFormer와 준비된 Whisper로 처리합니다. 원본·후보를 듣고 문장·인물을 골라 기존 자막을 남긴 채 추가합니다. 중지·폐기·실행 취소와 원본 스냅샷 확인을 유지합니다.

## Limits / 한계

- The synthetic mixed English/Korean source experiment loaded the real models and generated two candidate WAV/transcript results, but both transcripts leaned toward the English voice and **did not recover the Korean phrase**. This operational check does not establish Korean broadcast overlap quality, fewer omissions, speaker accuracy or faster editing. Music, shouts, laughter and more than two voices can cause damage, duplication or missing speech.
  / 영한 합성 겹침 소스 시험은 실제 모델·두 WAV/전사 결과 생성을 확인했지만 영어 쪽으로 치우쳐 **한국어 대사를 복원하지 못했습니다.** 한국어 방송 복원 품질·누락 감소·화자 정확도·편집 시간 단축을 입증하지 않습니다. 음악·고함·웃음·3인 이상에서 손상·중복·누락이 생길 수 있습니다.
- WeSpeaker/SepFormer/Whisper weights are prepared separately with explicit model controls; model presence is not a quality guarantee. Qwen remains source-only and is not included in the normal frozen runtime. No paid/cloud calls were made to validate these additions.
  / WeSpeaker·SepFormer·Whisper 가중치는 모델 준비 조작으로 별도 준비하며 존재만으로 품질을 보장하지 않습니다. Qwen은 소스 전용으로 일반 동결 실행환경에 포함하지 않습니다. 추가 기능 검증에 유료/클라우드 호출은 하지 않았습니다.
- Keep a project backup before editing in 0.3.6: new style fields may prevent older versions from reading the saved project. The updated parser accepts older styles. Other PCs need the same installed fonts; local ASS/libass rendering does not establish pixel parity in every player. YTT cannot preserve custom fonts, precise width/blur/offsets or both effects together; outline takes priority.
  / 0.3.6 편집 전 프로젝트를 백업하세요. 새 스타일 필드는 이전 앱에서 읽지 못할 수 있으며 새 앱은 기존 스타일을 읽습니다. 다른 PC에는 같은 글꼴이 필요하고 로컬 ASS/libass 렌더는 모든 플레이어의 픽셀 일치를 보장하지 않습니다. YTT는 실제 글꼴·정확한 두께/흐림/거리·두 효과 동시 표현을 보존하지 못하며 획이 우선합니다.
- Windows executables remain Authenticode-unsigned. Ed25519 update-manifest authentication and download SHA256 checks are separate from Windows publisher trust or installation success. Model weights, the NVIDIA driver, original media and third-party VST plugins are separate.
  / Windows 실행 파일은 Authenticode 미서명입니다. Ed25519 업데이트 명세 인증과 SHA256 다운로드 검증은 Windows 게시자 신뢰·설치 성공과 별개입니다. 모델 가중치·NVIDIA 드라이버·원본 미디어·외부 VST는 별도입니다.
