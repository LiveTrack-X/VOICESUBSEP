## Changes / 변경

- Keep **local Whisper + regular Nemotron** as the default. Alternative paid engines remain Advanced options. / 기본은 로컬 Whisper + 정식 Nemotron이며 대체 유료 엔진은 고급 설정에 둡니다.
- Live captions use persistent local models and 16 kHz PCM packets; roughly four-second recognition windows, cached models only. Microphone, system audio or both retain their original recording tracks. OBS receives a local read-only overlay with hide/clear controls. / 라이브 자막·입력 레벨·OBS 표시·원본 트랙 보존을 연결했습니다. 모델은 먼저 준비해야 합니다.
- Mixer preview supports the selected file/OBS track, solo, offsets and gain, with up to ten seconds of sample-peak/clipping feedback. / 믹서는 선택 트랙·솔로·최대 10초 미리듣기와 해당 구간 피크를 제공합니다.
- Includes the previously unshipped caption-first layout, document exports, speaker corrections, settings, diagnostics and provider fixes. / 자막 중심 화면·문서 출력·화자 보정·설정·오류 기록·공급자 수정도 포함합니다.
- GitHub split-asset updates verify an Ed25519-signed manifest and every SHA256 before installation. Check, download and install each require a user action. / 인앱 업데이트는 서명된 명세와 파일 해시를 검증하며 확인·다운로드·설치를 사용자가 각각 선택합니다.
- Subtitle translation and automatic AI summaries/Ollama remain removed as requested. / 요청에 따라 자막 번역·AI 자동 요약·Ollama를 제외했습니다.

## Installation and update scope / 설치·업데이트 범위

Use `VOICESUBSEP-0.3.0-Online-Setup-x64.exe` for one-file entry; it downloads and verifies the larger runtime. Models are separate. Manual installation uses the offline EXE plus reassembled `.nsis.7z` in the same folder. / 작은 Online EXE 하나로 시작하면 큰 실행환경을 받아 검증합니다. 모델은 별도이며 수동 설치는 Offline EXE와 조립한 데이터 파일을 같은 폴더에 둡니다.

Old v0.2.0/v0.2.1 builds have no update feed and require this installer once. The v0.3.0 app contains the public verification key for subsequent signed releases. Manifest signatures authenticate release files; they are **not Windows Authenticode signing**. / 기존 버전은 이번 설치본을 한 번 수동 설치해야 합니다. 이후 버전은 포함된 공개키로 검증합니다. 업데이트 명세 서명은 Windows 실행 파일 인증서 서명과 다릅니다.

## Public verification / 공개 검증

All ten public assets match the local files by GitHub size/SHA256. Anonymous downloads of the online EXE, manifest, detached signature and checksums match byte-for-byte. The app's updater accepts the public signature, offers 0.3.0 to an older-version test instance, and reports no update for 0.3.0. The full 2.42 GB payload was not downloaded again, and downloaded EXEs were not executed. Local installation above used the locally built, byte-identical release installer. / 공개 자산 10개의 크기·SHA256 일치, 온라인 EXE·명세·서명·체크섬 익명 다운로드 일치를 확인했습니다. 앱 업데이트 코드가 공개 서명을 받아 이전 버전에 0.3.0을 제안하고 현재 버전에는 업데이트 없음으로 응답했습니다. 2.42GB 전체 재다운로드나 다운로드한 EXE 실행은 하지 않았으며, 위 로컬 설치는 동일한 로컬 빌드 설치본으로 검증했습니다.

## Maintainer release steps / 다음 배포 절차

1. Run the test suites, build the backend, then web/desktop installer. Keep the existing application ID and public key. / 검사 후 백엔드→웹→설치기를 빌드하고 앱 ID·공개키를 유지합니다.
2. Split assets with `scripts/prepare-release-assets.py`, then sign `installer-manifest.json` using `node scripts/sign-update-manifest.cjs <release-directory>`. / 조각을 생성하고 명세를 서명합니다.
3. Pin the online helper with `scripts/pin-online-release.py <manifest>` and build it with `scripts/build-online-installer.ps1`. Add checksums for all public assets. / 온라인 도우미를 해당 해시로 고정해 빌드하고 전체 체크섬을 작성합니다.
4. Upload to a new draft release, verify names/sizes/hashes, then publish. Never replace assets under an already published signed version. / 새 초안에 업로드·검증 후 게시하며 공개된 버전 자산을 덮어쓰지 않습니다.

The private signing key stays outside the repository at `%LOCALAPPDATA%\VOICESUBSEP-ReleaseKeys\update-ed25519.pem`, or an explicit `VOICESUBSEP_RELEASE_KEY` path. Back it up securely for future releases; the app receives only `desktop/update-public-key.pem`. / 개인 서명키는 저장소 밖에서 보관·백업하고 앱에는 공개키만 넣습니다.
