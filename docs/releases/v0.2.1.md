## Remaining validation and release limits / 남은 검증·배포 제한

- Paid adapters use fake transports/local fixtures; real account authentication, billing, latency and speech/speaker quality
  remain unverified. / 유료 어댑터는 모의 전송·로컬 자료 검사이며 실제 계정·과금·지연·인식 품질은 미검증입니다.
- Office ZIP/XML checks do not establish every Word/Excel application rendering. Real audio-interface recording,
  long-session recovery and overlapping-speech quality need separate user-file/device validation.
  / Office 구조 검사와 실제 Word/Excel 표시는 별개이며 실기기 장시간 녹음·복구·동시 발화 품질은 별도 검증합니다.
- Qwen's source adapter has mock tests and native tokenizer smoke only; no speech weights or quality run.
  Its tokenizer license declarations conflict, so default frozen builds exclude it and an explicit inclusion request is blocked.
  / Qwen은 개발 환경 모의 검사·토큰화 확인만 했으며 실제 모델 추론은 미검증입니다. 라이선스 표시 불일치로 설치본에서 제외합니다.
  See [Qwen runtime status](../QWEN-RUNTIME.md).
- Code signing and the in-app update feed remain unconfigured. Model weights and external VST plugins are separate.
  Original notices do not by themselves settle all redistribution obligations. / 코드 서명·업데이트 feed는 미설정이며 모델·VST는 별도입니다.
  See [bundled notices](../BUNDLED-NOTICES.md).
- Recording still analyzes after stopping. OBS live delivery, stable live speaker IDs and arbitrary WASAPI/ASIO routing
  remain future work. / 녹음은 종료 후 분석이며 OBS 실시간 송출·라이브 화자 고정·임의 WASAPI/ASIO 라우팅은 후속 작업입니다.
