# VOICESUBSEP v0.2.1 Windows Preview

This preview makes subtitles the main editing pane, adds a speaker transcript document, recognition previews and report exports, and introduces optional Groq/xAI processing. Wide windows place a compact adjustable preview beside captions; narrow windows start in subtitle focus view. Notes are collapsed by default, and preview height/collapse controls keep playback available.

자막을 주 편집 영역으로 배치하고 인물별 발언록·인식 중 미리보기·보고서 출력·선택적 Groq/xAI 처리를 추가합니다. 넓은 창에서는 작은 미리보기 옆에 자막을 두고, 좁은 창에서는 자막 집중 보기로 시작합니다. 메모는 기본 접힘이며 미리보기 높이 조절·접기 후에도 재생 컨트롤을 사용할 수 있습니다.

- Notes remain available through expand/collapse, and selecting a timeline note opens its card. Note cards stack vertically without horizontal overflow. / 메모 펼침·접기와 타임라인 메모 선택은 유지하며, 카드는 가로 넘침 없이 세로로 표시합니다.
- The desktop window can shrink to 480 px wide for side-by-side editing. / 설치형 앱 창도 너비 480px까지 줄여 나란히 편집할 수 있습니다.
- Projects, captions, notes, names, and saved layout preferences are not migrated or cleared by this fix. / 이 수정은 프로젝트·자막·메모·이름·기존 레이아웃 저장 값을 삭제하거나 변환하지 않습니다.
- Workspace buttons clearly open subtitle/video editing, interviews/minutes or recording. Documents and recording share the project and return to editing when closed. / 상단 작업 버튼으로 자막·영상 편집, 인터뷰·회의록, 녹음을 구분합니다. 같은 프로젝트를 유지하고 문서·녹음 창을 닫으면 편집으로 돌아갑니다.
- Speaker inputs show actual assigned speakers when captions exist. An expected count of one does not silently merge existing identities; an explicit destination/count confirmation performs an undoable merge. / 자막이 있으면 실제 배정된 인물을 표시합니다. 예상 1명 선택만으로 기존 인물을 합치지 않으며 대상·수량 확인 후 통합하고 실행 취소할 수 있습니다.
- Interview/minutes outputs include standalone HTML reports, PDF through print preview, and actual XLSX workbooks. Times, review state and evidence remain visible. / 인터뷰·회의록은 독립 HTML 보고서, 인쇄 미리보기의 PDF 저장, 실제 XLSX 통합문서를 지원합니다. 시간·검수 상태·근거를 보존합니다.
- Documents open with a chronological **speaker: utterance** transcript. Export editable Word DOCX or UTF-8 TXT without AI, optionally including source timestamps. Interview Q&A and AI meeting summaries remain separate tabs. / 문서 창은 **인물: 발언** 형식의 시간순 발언록으로 시작합니다. AI 없이 Word DOCX·UTF-8 TXT로 저장하고 원본 시간 표시를 선택합니다. 인터뷰 문답과 AI 회의 요약은 별도 탭입니다.
- Microphone permission/device refresh reads actual available device names and releases the temporary stream. Removed selected devices cannot silently fall back to the default input. / 마이크 권한 확인·장치 새로고침으로 실제 장치 이름을 읽은 뒤 임시 스트림을 해제합니다. 선택 장치가 사라져도 기본 입력으로 몰래 전환하지 않습니다.
- Advanced provider settings keep local processing as the default and offer Groq/xAI speech recognition, translation and minutes with explicit transmission confirmation and session-only keys. / 고급 공급자 설정은 기본 로컬 처리를 유지하며 전송 확인·세션 키를 사용한 Groq/xAI 음성 인식·번역·회의록 생성을 제공합니다.

## Artifact and validation scope / 산출물·검증 범위

During transcription, the dialog displays the latest two completed ASR segments as a draft, alongside elapsed time and processing stage. The preview is bounded to two segments of at most 500 characters each, visually shortened in narrow windows. It updates as segments arrive, rather than streaming incomplete tokens. It does not assign speakers or apply unfinished captions. Single-source and isolated-track analysis share the preview contract.

전사 중 최근 ASR 구간 두 개를 초안으로 표시하고 경과 시간·처리 단계를 함께 보여줍니다. 각 구간은 최대 500자로 제한하고 좁은 창에서는 짧게 표시합니다. 미완성 토큰을 흘리는 대신 구간이 인식될 때 갱신하며, 인물 배정이나 미완성 자막 적용은 하지 않습니다. 일반 음원과 인물별 분리 트랙 분석에 같은 미리보기 규칙을 사용합니다.

The app and rebuilt Python backend are version 0.2.1. Model dependencies remain unchanged; this update does not require new model weights. The original v0.2.0 tag and release files are preserved.

앱과 다시 빌드한 Python 백엔드는 0.2.1입니다. 모델 의존성은 같아서 이번 변경 때문에 모델 가중치를 다시 받을 필요는 없습니다. 기존 v0.2.0 태그·파일은 보존합니다.

This remains an unsigned preview with no configured in-app update feed. Models and external VST plugins are separate. Source notices and dependency versions are unchanged; see [bundled notices and source locations](../BUNDLED-NOTICES.md). Full speech accuracy, real-device long recording and overlapping-speech recovery remain outside this patch's validation.

코드 서명과 인앱 업데이트 feed가 없는 Preview이며 모델·외부 VST는 별도입니다. 포함 고지와 의존성 버전은 같으며 [고지·원본 소스 위치](../BUNDLED-NOTICES.md)를 확인할 수 있습니다. 인식 정확도·실기기 장시간 녹음·겹친 발화의 복원 품질은 이번 화면 수정의 검증 범위에 포함하지 않습니다.

Cloud adapters are checked with simulated responses and local requests without real provider keys or paid calls. This does not establish service availability, billing, latency, or semantic quality for a real account. PDF report preview is verified in the browser; native PDF save requires a printing-capable browser/desktop environment. XLSX ZIP/XML integrity and literal text handling are checked separately. See [advanced providers](../ADVANCED-PROVIDERS.md) for transmission/authentication limits.

클라우드 어댑터는 실제 공급자 키·유료 호출 없이 모의 응답과 로컬 요청으로 검사합니다. 실제 계정의 서비스 가용성·과금·지연·내용 품질을 입증하지는 않습니다. 브라우저의 PDF 보고서 미리보기를 확인하며 실제 PDF 저장에는 인쇄를 지원하는 환경이 필요합니다. XLSX ZIP/XML 구조와 텍스트 보존은 별도로 확인합니다. 외부 전송·인증 범위는 [고급 공급자 설정](../ADVANCED-PROVIDERS.md)을 따릅니다.

[OBS live speaker captions](../OBS-LIVE-CAPTIONS-PLAN.md) are a separate future development unit; this release's recorder still analyzes after stopping.

[OBS 실시간 인물별 자막](../OBS-LIVE-CAPTIONS-PLAN.md)은 별도 후속 개발 단위입니다. 이번 릴리즈의 녹음은 계속 종료 후 분석 방식입니다.
