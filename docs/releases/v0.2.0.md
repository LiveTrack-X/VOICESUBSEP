# VOICESUBSEP v0.2.0 Windows Preview

대상: Windows x64, **비공개 저장소의 시험 릴리즈(prerelease)**. 2026-09-25 만든 설치 EXE와 세 개의 분할 데이터를 기준으로 기록합니다. 코드 서명과 인증 업데이트 feed가 없는 수동 설치용 Preview입니다. 번들 실행과 데이터 무결성을 확인했으며 설치기를 실제 실행한 검증은 포함하지 않습니다.

[사용자 가이드](../USER-GUIDE.md) · [문서 목차](../INDEX.md) · [공식 Releases](https://github.com/LiveTrack-X/VOICESUBSEP/releases)

## 이번 버전에 포함한 기능

- **인물별 자막:** 로컬 faster-whisper의 large-v3/large-v3-turbo와 Nemotron, 음성 언어 AUTO/직접 선택, 짧은 단어 화자 경계 보정, 분리 녹음된 OBS 오디오 트랙을 인물별로 연결해 순차 전사.
- **자막 편집:** 인물 이름·색·자막별 스타일, 타임라인 탐색·메모, 높이 조절·접기·집중 보기, 100행 페이지, 일괄 인물·검수·삭제·문자열 치환, 파형과 자막 경계 조절.
- **출력:** 전체/인물별 SRT, 스타일 ASS, 인물별 SRT·메모 ZIP, 구간 제외·복원과 MP4/WAV/MP3/M4A 렌더, 원본 프레임률·30·60fps 및 편집본 시간의 자막·메모.
- **복구와 이력:** 프로젝트 자동 저장·이전 정상본 복구·오류 원본 보관, 분석·렌더 작업 재열기, 렌더 시점 프로젝트 보존, 같은 미디어 사본 재사용과 참조를 보호하는 수동 캐시 정리.
- **문서와 언어:** 한국어·일본어·영어·중국어 간체·스페인어 UI와 자막 번역, 인터뷰 역할·질문/답변 분류, 원문 근거가 있는 수동 회의록 및 로컬 Ollama 초안.
- **녹음:** 마이크·시스템 소리·혼합본 보관, 약 1초 단위 IndexedDB 기록과 중단 조각 복구, 녹음 종료 후 새 프로젝트에서 분석.
- **VST와 진단:** 설치된 외부 VST3 효과 최대 4개 전처리, 플러그인 보고 지연별 보정, A/B 비교, 설정 JSON 백업·복원과 오류 로그 내보내기, 앱 아이콘 통일.

기능별 절차와 제한은 [편집 워크플로](../EDITING-WORKFLOWS.md), [컷·번역 계약](../CUTS-AND-LANGUAGES.md), [VST 체인](../VST-CHAIN.md)에 있습니다.

## 수정한 주요 문제

1. 긴 자막 합치기·치환이 저장 한도를 넘어 잘못된 자동 저장을 만드는 문제를 변경 전 검증과 저장 검증으로 막습니다.
2. 렌더·VST 상태 조회 중 연결 끊김 또는 404로 창을 닫지 못하는 문제를 처리합니다.
3. 같은 미디어의 중복 업로드·사본 누적을 줄이고 수동 정리 경로를 제공합니다.
4. 자막이 없는 프로젝트에서도 첫 자막을 추가할 수 있습니다.
5. 공백 없는 긴 문자열이 자막 목록 너비를 밀어내는 문제를 수정합니다.
6. 백엔드 실행 파일 누락과 같은 앱 시작 오류를 로그 초기화 이후에 처리합니다.

새 프로젝트에서 이전 인물·실행 취소 상태가 섞이지 않도록 프로젝트 경계를 유지합니다. 회의록 근거의 원문·시간·인물이 바뀌면 재검수 상태로 표시합니다.

## 지원 범위와 알려진 한계

- 화자 구분은 음원 분리가 아닙니다. 이미 한 트랙에 섞인 동시 발화의 모든 대사 복원을 보장하지 않습니다. `4명 이상`은 최소 4명 기준이며 모델은 최대 8개 화자 채널을 제공합니다.
- 녹음은 종료 후 분석합니다. 스트리밍 ASR, 지속적인 화자 ID 고정, 외부 오디오 드리프트 보정, 장치 자동 재연결은 미구현입니다. 긴 실제 방송·회의의 연속 녹음 안정성과 인식 품질은 별도 확인이 필요합니다.
- 최종 렌더는 오디오 트랙 하나를 선택합니다. 여러 트랙의 gain/mute/믹스, 여러 영상 배치, 자막을 영상에 직접 입히는 기능은 없습니다. 원본 프레임률 선택도 고정 프레임률 재인코딩입니다.
- 프로젝트 JSON에 원본 미디어는 포함되지 않습니다. 재연결 시 파일명·길이 확인은 전체 원본의 해시 동일성 보장을 대신하지 않습니다.
- Ollama와 모델, CLEAR/RX 등 외부 VST3 플러그인은 별도 준비합니다. Whisper·Nemotron 가중치는 설치 파일에 포함하지 않으며 첫 실행에 대용량 다운로드가 필요할 수 있습니다.
- 번역·회의록 생성 결과는 검토할 초안입니다. 근거 ID와 값의 검증은 의미 정확성, 모든 언어 품질, 전체 회의 결론의 자동 합성을 보장하지 않습니다.
- macOS/Linux 설치 패키지, 코드 서명 신뢰도, 원격 인앱 업데이트 성공은 Windows 소스 빌드·단위 테스트와 별개입니다.

## 설치와 이전 버전에서 이동

GitHub 자산의 크기 제한에 맞춰 `.nsis.7z` 데이터는 1GiB 단위 `.part001`부터 마지막 조각까지 분할합니다. EXE·모든 조각·`installer-manifest.json`·`SHA256SUMS.txt`·`Assemble-Installer.ps1`을 같은 폴더에 내려받고 아래 명령으로 해시 확인·재조립합니다. 성공하면 EXE를 직접 실행합니다. 기존 작업의 프로젝트 JSON을 저장하고 원본 미디어를 별도로 보관한 뒤 앱을 종료하세요. 자세한 단계는 [설치 안내](../USER-GUIDE.md#1-설치와-첫-실행)를 따릅니다.

```powershell
powershell -NoProfile -File .\Assemble-Installer.ps1
```

설치 데이터는 2,416,033,719바이트(약 2.42GB), 압축 해제한 앱은 5,440,162,807바이트입니다. 다운로드 조각·재조립 파일·설치본을 함께 보관할 공간으로 약 15GiB 이상과 별도 모델 여유 공간을 권장합니다.

같은 앱 ID를 유지하며 사용자 데이터·자동 저장·모델 캐시는 설치 폴더 밖에 보관하도록 구성합니다. 이전 버전의 앱에서 새 문서·번역·컷 데이터를 안전하게 편집할 수 있다고 보장하지 않으므로 업데이트 전 JSON 백업을 별도로 남기세요. 진행 중인 분석·렌더는 재시작 후 자동 재개하지 않습니다.
