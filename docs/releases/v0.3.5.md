## Changes / 변경 사항

- **Evidence-based unassigned-speaker review.** Shows why a caption is unassigned and offers conservative boundary suggestions. Listen to the original, choose captions and apply as one undoable edit. Manual/reviewed captions, changed suggestions and overlapping speech are protected. Older projects without evidence remain explicitly unknown; no new analysis or bulk reassignment starts automatically.
  / **근거 기반 미배정 화자 검토:** 미배정 원인과 보수적인 경계 후보를 보여줍니다. 원음을 듣고 자막을 골라 실행 취소할 수 있는 하나의 편집으로 적용합니다. 수동 수정·검수 자막·변경된 후보·겹친 발화를 보호합니다. 근거가 없는 이전 프로젝트는 계속 미확인으로 표시하며 분석이나 일괄 재배정을 자동 실행하지 않습니다.
- **Native VST window status and focus.** Distinguishes requesting, preparing, opening and visible-window states; lets you bring the same plugin window forward. Clear native initialization still measured about 8.09 seconds in three local fresh-process pairs. Actual plugin GUI compatibility was not verified.
  / **VST 전용 창 상태·앞으로 가져오기:** 요청·준비·열기·창 표시 상태를 나누고 같은 플러그인 창을 앞으로 가져옵니다. Clear 네이티브 초기화는 새 프로세스 3쌍 비교에서 약 8.09초로 여전히 느립니다. 실제 플러그인 GUI 호환성은 검증하지 않았습니다.
- **Protect large-project saves.** When optional speaker evidence pushes a save over the 8 MiB project limit, the app reduces that optional evidence and reports the change; caption wording and times remain.
  / **대형 프로젝트 저장 보호:** 선택형 화자 근거로 프로젝트가 8MiB 저장 제한을 넘으면 그 근거를 줄여 저장하고 알립니다. 자막 문장과 시간은 유지합니다.
- **Correct link destinations.** The header logo opens this VOICESUBSEP repository; “Created by LiveTrack” opens the creator profile. The README now presents the product, download, workflow, setup requirements and limits before developer material.
  / **링크 목적지 수정:** 상단 로고는 VOICESUBSEP 저장소, “Created by LiveTrack”은 제작자 프로필로 연결합니다. README는 제품 소개·다운로드·작업 흐름·설치 요구사항·한계를 개발 안내보다 먼저 보여줍니다.
