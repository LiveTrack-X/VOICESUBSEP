# VOICESUBSEP 0.3.2 — preparation record / 준비 기록

**Status on 2026-09-25: source validation in progress; not published or installed.** The currently available download remains [0.3.1](v0.3.1.md). This record describes 0.3.2 source changes and completed checks, not an available installer. Frozen-runtime/package checks, final source CI, publication and installation remain separate acceptance steps. The 0.3.1 release, tag and evidence are unchanged.

**2026-09-25 상태: 소스 검증 중·미게시·미설치입니다.** 현재 다운로드는 [0.3.1](v0.3.1.md)입니다. 이 문서는 0.3.2 소스 변경과 수행한 검사를 기록하며 설치 파일 제공을 뜻하지 않습니다. 동결 실행환경·패키지, 최종 소스 CI, 게시, 설치는 별도로 확인합니다. 0.3.1 릴리즈·태그·당시 증거는 변경하지 않습니다.

## Changes / 변경 내용

| English | 한국어 |
| --- | --- |
| Each ordinary file analysis runs in a dedicated child process. When supported, force-stop targets that owned process tree, preserving the app/backend and other jobs. The next analysis starts only after exit confirmation; failed cleanup pauses the queue. | 일반 파일 분석을 작업별 전용 자식 프로세스에서 실행합니다. 지원되는 작업의 강제 종료는 그 소유 프로세스 트리만 대상으로 하고 앱·백엔드·다른 작업을 유지합니다. 종료 확인 후에만 다음 작업을 실행하며 정리 실패 시 큐를 보류합니다. |
| Queue controls retain cooperative cancellation and add force-stop-and-prioritize. Confirmation identifies the current blocking job; a changed target is rejected. History refreshes active entries and the selected job/result without closing and reopening. | 기존 일반 중단에 강제 종료 후 우선 실행을 추가합니다. 확인한 현재 작업만 대상으로 하며 바뀐 대상은 거부합니다. 작업 이력은 진행 항목과 선택 작업·결과를 창 재열기 없이 갱신합니다. |
| Uploaded source SHA256 and byte count bind edits to content. A renamed identical original preserves cuts; different content requires explicit new-project confirmation. Legacy projects require explicit first binding instead of trusting filename/duration. Late upload responses cannot bind to a switched project. | 업로드 원본의 SHA256·바이트 수로 편집을 내용에 연결합니다. 이름만 다른 같은 원본은 컷을 보존하고 다른 내용은 새 프로젝트 확인이 필요합니다. 옛 프로젝트는 파일명·길이를 신뢰하지 않고 첫 연결을 확인합니다. 프로젝트를 바꾼 뒤 도착한 업로드 결과는 적용하지 않습니다. |
| Raw-media upload no longer has a fixed byte cap; the retired `VOICESUBSEP_MAX_UPLOAD_BYTES` environment setting is ignored. Multipart disk spooling, 1 MiB copy/hash reads, format checks, cancellation cleanup and disk-error reporting remain. Separate JSON, live and provider limits are unchanged. | 원본 업로드 고정 용량 상한을 제거하고 기존 `VOICESUBSEP_MAX_UPLOAD_BYTES`를 무시합니다. multipart 디스크 임시 저장·1MiB 복사/해시·형식 확인·취소 정리·디스크 오류 처리는 유지합니다. JSON·라이브·공급자별 한도는 별개로 유지합니다. |
| Bound single-source exports rehash the actual cached file immediately before rendering, in cancellable 1 MiB blocks. Same-size changes and missing/corrupt saved snapshots fail safely. Mix/preview queues retain their separate per-track identity contract. | 원본이 등록된 단일 파일 출력은 렌더 직전 실제 캐시 파일을 취소 가능한 1MiB 블록으로 재검증합니다. 같은 크기의 내용 변경·작업 스냅샷 소실/손상은 실패 처리합니다. 믹스·미리듣기는 별도의 트랙별 식별 계약을 유지합니다. |
| Meaningful text/speaker edits clear reviewed status and add manual-edit review; time edits add timing review. No-op/style-only edits preserve review. Transcript links pass caption IDs, selecting the intended cue even when speakers share a start time. | 실제 내용·화자 변경은 검수 완료를 해제하고 수동 수정 사유를, 시간 변경은 시간 검수 사유를 남깁니다. 변경 없음·스타일만 수정은 유지합니다. 발언록 링크는 자막 ID로 같은 시작 시각의 다른 인물도 정확히 선택합니다. |
| Capture remembers microphone/system/both and a chosen microphone within the current profile. Restoring settings neither starts recording nor bypasses permissions; missing fixed inputs are not silently replaced. | 녹음은 현재 프로필에서 마이크·시스템·둘 다와 선택 마이크를 기억합니다. 복원만으로 녹음·권한 승인을 실행하지 않고 사라진 고정 입력을 임의 대체하지 않습니다. |
| VST processing compensates reported delay, then checks real input/output windows for residual delay per effect. Extra shifts require strong, unambiguous agreement; insufficient, periodic, gated, changing or negative-delay evidence adds no guessed compensation. | VST 보고 지연 보정 후 효과별 실제 입출력의 여러 구간에서 잔여 지연을 측정합니다. 충분하고 모호하지 않은 일치 때만 추가 보정하며 짧음·주기음·게이트·가변·음수 지연은 추측해 이동하지 않습니다. |

Force-stop is not a hard real-time GPU guarantee and cannot undo cloud uploads or charges. Windows owned-process cleanup is the verified runtime scope; equivalent POSIX cleanup and real driver hangs are not established. Isolation can reload models for each job, so preparation time may recur. No user job was stopped for the checks below.

강제 종료는 GPU 즉시 종료 시간을 보장하지 않으며 클라우드 전송·과금을 되돌리지 않습니다. 검증 범위는 Windows 소유 프로세스 정리이며 POSIX의 동등한 정리·실제 드라이버 멈춤은 미검증입니다. 격리 때문에 작업마다 모델을 다시 불러와 준비 시간이 반복될 수 있습니다. 아래 검사에서 실제 사용자 작업을 중단하지 않았습니다.

See the [format guide](../YOUTUBE-CAPTIONS.md). / **YTT 소스 추가·검증 중:** SRV3/YTT로 인물 이름 색과 자막 색·크기·위치·배경을 출력합니다. 원본/컷 적용 시간을 고르며 컷 경계 대사의 근거가 불확실하면 편집본 출력을 막습니다. YouTube 업로드·표시 미검증, 고급 애니메이션·노래방·참고 영상 효과 재현 제외입니다. [형식 안내](../YOUTUBE-CAPTIONS.md)를 참고하세요.

## Compatibility / 호환성

Old project JSON remains readable. New projects carrying the `edited` review reason may be rejected by 0.3.1's strict parser; keep a separate pre-upgrade JSON if rollback matters. The optional source identity records a SHA256 and byte count, not the original media itself. Legacy sources still require the user's first-binding judgment. Autosave is not an original-media backup.

기존 프로젝트 JSON은 계속 읽습니다. 새 `edited` 검수 사유가 들어간 프로젝트는 0.3.1의 엄격한 파서가 거부할 수 있으므로 복귀가 필요하면 업그레이드 전 JSON을 따로 보관하세요. 선택적 원본 식별 정보는 SHA256·바이트 수이며 원본 파일 자체가 아닙니다. 옛 프로젝트의 첫 원본 판단은 사용자가 확인해야 하고 자동 저장은 원본 백업이 아닙니다.

Subtitle translation and automatic AI/Ollama summaries remain removed by user decision. The default remains local Whisper + Nemotron; optional paid ASR/diarization and source-only Qwen retain their documented limits. No recognition-quality improvement is claimed solely from these tests.

사용자 결정으로 제거한 번역·AI/Ollama 자동 요약은 복원하지 않습니다. 기본은 로컬 Whisper+Nemotron이며 선택 유료 인식·화자 API와 개발 환경 전용 Qwen의 기존 한계를 유지합니다. 이번 검사만으로 음성 인식 정확도 개선을 주장하지 않습니다.
