# VOICESUBSEP icon

The application mark is a white speech bubble and a five-bar waveform on an indigo/violet tile. Three violet bars and two mint bars suggest separate speakers. It is shared by the Windows application, installer/uninstaller, browser favicon and editor header.

- `icon-master.png`: original generated RGBA artwork (1254 x 1254), preserved unchanged.
- `icon.png`: 512 x 512 PNG for the runtime window icon on non-Windows platforms.
- `icon.ico`: Windows RGBA PNG frames at 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels.
- `../../public/app-icon.png`: 128 x 128 web/header asset.
- `../../public/favicon.png`: 32 x 32 browser asset.
- `../../public/favicon.ico`: the same multi-size Windows icon for browser fallback.

The master was created with the built-in `image_gen` tool on 2026-09-24. Derived assets only resize and encode the original with Lanczos3 via Sharp; the composition and alpha are preserved. Previewed at actual sizes on light and dark backgrounds. No fonts or remote image services are required at runtime.

## Generation prompt

Square 1024 x 1024 PNG composition, genuinely transparent outside a large rounded-square tile. Tile fills about 94% of canvas with a clean rich deep violet to indigo subtle diagonal gradient, no external shadow. A single bold near-white speech bubble silhouette centered on the tile, with a small lower-left tail and a distinctive broad audio waveform inside it made of 5 thick rounded vertical bars in deep violet, the last two bars in bright mint teal to convey two speakers separated into subtitles. Waveform has a clear varied-height rhythm and generous spacing. Strong simple geometry, generous optical margins, carefully balanced, premium desktop utility identity. Instantly readable at 16px, 24px and 32px. No text, no letters, no headphones, no microphone stem, no atom symbol, no badges, no borders around canvas, no decorative tiny details, no photorealism, no mockup. Flat vector-like geometric artwork with crisp antialiasing. Return only the one icon asset.
